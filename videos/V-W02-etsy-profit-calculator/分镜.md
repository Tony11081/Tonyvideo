# V-W02 分镜（v1，18 秒，60 帧，120 BPM）

网站宣传片之二：Etsy 利润计算器（openaigrowth.com/tools/etsy-profit-calculator）。竖版 1080×1920（抖音），横版 1920×1080，同一条时间线（`timelineA.js`）。

**一句话概念**：一笔 30 美元的 Etsy 订单用第一人称讲自己。它是一根荧光绿的长条，右端的光点就是它自己；每扣一笔钱，长条就从右边被切掉一段，光点跟着往回退。观众看着 $30 一段段变成 ¥64.94，再在 drop 处被站外广告切到 ¥33.31。计算过程就是画面本身。

## 事实出处

所有数字都是网站利润计算器在默认示例下的计算结果：直接用仓库里的 `src/lib/calculator/profit.ts`（`calculateProfit`、`solvePrice`、`defaultProfitInput`）跑出来，费率表 `src/lib/calculator/fee-rates.ts` 核对日期 2026-10-08，2026-10-13 复算。画面左下角常驻示例条件脚注。

- 示例输入：售价 $25 + 买家运费 $5（订单 $30），收款地中国，汇率 7.10，提现 1%，商品成本 ¥40，包装 ¥5，物流 ¥70。
- Etsy 收费：上架费 $0.20；交易费 6.5% × $30 = $1.95；支付处理费（中国）6.5% × $30 + $0.30 = $2.25；合计 $4.40，占 14.7%。
- 到账 $25.60，提现 1% 后 $25.34 = ¥179.94；减成本 ¥115 后利润 ¥64.94，利润率 30.5%。
- 站外广告 15%：广告费 $4.50，利润 ¥33.31，利润率 15.6%。
- 站外广告规则「只对归因订单计费：12% 或 15%，单笔上限 $100」是计算器页面「费率与估算口径」里的原话。
- 结尾三条功能：17 个收款地区的支付处理费率（`bankRegions` 共 17 个）；站外广告 12% / 15% 对比（计算器选项）；反推保本价和目标利润率售价（`solvePrice`，示例保本价 $14.39，30% 利润率售价 $24.73）。
- 「免费 · 不用登录」：计算器页面原文「免费计算，无需登录」。

## 视觉与声音

- 配色同 V-W01 和网站：背景 #050505，荧光绿 #c8ff00 代表「还剩下的钱」，Etsy 收费琥珀色 #ffb224，结汇灰蓝，成本灰色。
- 字体：Geist、JetBrains Mono、Noto Sans CJK SC；金额用等宽数字。
- 音乐和音效：本机原创合成（`music_a.py`），没有使用任何素材库；A 小调，120 BPM，Am9–Fmaj7–Cmaj7–G6，第 20–22 拍断拍加上升音，第 22 拍 drop，结尾 Cmaj9。每切一刀一个「剪」声，音高逐刀下降；换汇、出结果、开关、功能条目都有对应音效；母带 −14.3 LUFS，真峰值 −1.0 dBFS。
- 制作：与 V-W01 相同管线（逐帧确定性 HTML → Playwright → 自适应运动模糊 → H.264）。

## 重新出片

```sh
cd source   # 需要 npm i playwright sharp，以及 Chromium 和 ffmpeg
node -e "const T=require('./timelineA.js');require('fs').writeFileSync('eventsA.json',JSON.stringify({BEAT:T.BEAT,duration:T.duration,at:T.at,cuts:T.cuts.map(c=>c.at)}))"
python3 music_a.py                                  # → mix_a.wav（已是 −14 LUFS 左右，直接用）
FILM=filmA.html node render_av.mjs 1080 1920 v.mp4  # 竖版无声
FILM=filmA.html node render_av.mjs 1920 1080 h.mp4  # 横版无声
```
