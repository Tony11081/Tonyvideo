# V-W01 分镜（v2，24 秒，60 帧，120 BPM）

网站宣传片：openaigrowth.com（Shopwright）。竖版 1080×1920（抖音），横版 1920×1080（网站 / YouTube），同一条时间线。

**v2 改动（10-13，按 Lambert 意见「ETSY 元素要多些，客户看了半天不知道什么工具」）**：第 0 帧直接打出「FOR ETSY SELLERS / Etsy 卖家工具站 / 标题 · 标签 · 利润 · 上架」；每句字幕都点明 Etsy；从第 1.5 秒起底部常驻站名条「Etsy 卖家工具站 · openaigrowth.com」；三个版块眉标改为 ETSY WORKBENCH / FREE ETSY TOOLS / ETSY PIPELINE；镜头运动改用三次缓动，并按运动量自适应 4–16 个子帧做运动模糊，快速平移不再重影。

**一句话概念**：「Shopwright.」末尾的荧光绿句号是主角，用第一人称讲述。它从输入框里的光标出发，依次穿过标题、标签、工作台、免费工具和流水线，最后回到字标里，变回那个句号。镜头沿真实首页的版块顺序一镜到底往下走，转场全部由画面元素长出来，不用淡入淡出。

## 事实出处

画面里的界面文字、数字和模块名全部取自 openaigrowth.com 线上首页和仓库源码（`src/components/tech-home.tsx`、`src/lib/workbench-tools.ts`），2026-10-13 核对，没有编造的用户数、销量或评价。

- 终端演示：`skill/listing · run 0428`；输入 Maple cake server set / Laser engraving / 2 fonts · 3 woods / unknown: Blade steel grade；输出标题（74 个字符，上限 140）和 13 个标签；`facts checked · 1 unknown flagged`。与首页 hero 演示一致。
- 工作台演示：已放入的 6 个模块，以及从功能库拖入「原创产品方向」，与首页「工作台，你说了算」演示一致。
- 免费工具 6 个：利润计算器、合作定价核算、标题字符检查、13 标签检查、AI 披露文案、运费计费重。「74/140 ✓」「13/13 ✓」是同一条演示 listing 的真实检查结果（标题 74 字符，标签 13 个）。
- 流水线 7 步：产品机会分析 → 原创产品方向 → 工艺审查 → 设计系列 → SKU 与定制选项 → 上架资料包 → 15 图拍摄规划。
- 结尾文案「Etsy 卖家工具站，按你的方式组装。」/ "Your Etsy toolkit, built your way." 是首页标题和英文站标语。

## 视觉与声音

- 配色取自网站：背景 #050505，正文 #f4f4f5，强调色只有荧光绿 #c8ff00，未确认项用琥珀色 #ffb224；静态胶片颗粒和点阵与首页一致。
- 字体：Geist（无衬线），JetBrains Mono（等宽，网站等宽字体的回退字体），中文 Noto Sans CJK SC。
- 音乐和音效：本机原创合成（`music.py`），没有使用任何素材库；A 小调，120 BPM，第 16 拍 drop；打字、标签弹出、卡片落位、点击、流水线节点的音效都放在画面时间线对应的位置；母带 −14 LUFS，峰值 −1.9 dBFS。音乐合成时用的拍点和画面共用 `timeline.js`。
- 制作：HTML 按时间逐帧计算（同一个时间永远渲染出同一帧），Playwright 逐帧截图；`render_av.mjs` 按每帧的屏幕运动量取 4–16 个子帧（180° 快门）合成运动模糊，ffmpeg 编码 H.264（CRF 16）。

## 重新出片

```sh
cd source   # 需要 npm i playwright sharp，以及 Chromium 和 ffmpeg
node -e "const T=require('./timeline.js');require('fs').writeFileSync('events.json',JSON.stringify({BEAT:T.BEAT,duration:T.duration,at:T.at,typing:T.typing.map(k=>k.t),tags:T.tagTimes,tokens:T.tokenTimes}))"
python3 music.py                                   # → mix.wav
node render_av.mjs 1080 1920 v.mp4                 # 竖版无声（自适应运动模糊）
node render_av.mjs 1920 1080 h.mp4                 # 横版无声
# 合成：见 mux 命令（音频 volume=-0.95dB 后 AAC 256k）
```
