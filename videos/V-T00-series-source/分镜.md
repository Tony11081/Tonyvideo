# V-T01–V-T05 单工具系列 分镜（v1，每条 15 秒，1080×1920，30 帧，120 BPM）

openaigrowth.com 免费工具，一条只讲一个问题：先抛问题（第 0 帧就是问题），再把工具的算法演示一遍，最后给工具名和网址。五条共用一套版式、主角光点和配乐（`filmT.html?ep=…`、`music_t.py`），各自的音效踩在各自画面的节点上。

共用结构：0–1.5 s 问题 + 大号提示字；1.5–1.75 s 提示字上移，光点飞进演示区；1.75–11.8 s 演示；12–15 s 工具名（光点落成句号）+「免费，不用登录」+ openaigrowth.com + 工具路径。底部常驻「Etsy 卖家工具站 · openaigrowth.com」，演示区下方常驻示例 / 规则来源脚注。

## 事实出处（2026-10-13 核对仓库 tony11081/openaigrowth）

- 工具清单、名称、路径：`src/lib/workbench-tools.ts` 的 `freeTools`；「免费、无需登录」见工具页文案。
- **V-T01 13 标签检查**（/tools/tag-checker）：工具检查数量 13、每个 ≤ 20 字符、重复（不分大小写）和非法符号（`checkListing`）。13 个标签与 20 字符上限出自 Etsy 帮助中心 How to Use Tags（`toolSources.tags`）。示例标签为网站首页演示商品的 13 个标签；演示里故意放进去的两个错误（"personalized cake server set" 28 字符；"Cake Server Set" 与 "cake server set" 重复）就是工具会标出的两类问题，之后换回原标签。「相关性和商品事实仍需你核对」是工具原文的意思。
- **V-T02 标题字符检查**（/tools/title-counter）：140 字符上限出自 Etsy 帮助中心 How to Create a Listing（`toolSources.title`）。「最重要的词组放进前 40 个字符」「不写 Best / Perfect / Beautiful / Amazing / Sale / Free Shipping」来自网站内置的 Etsy-Tony 标题方法（`src/lib/skill-ai.ts`、`src/lib/listing-checks.ts` 的 `TITLE_BANNED`），画面脚注写明出处。示例标题为首页演示标题，74 字符；「Personalized Maple Cake Server Set」34 字符。
- **V-T03 运费计费重**（/tools/shipping-weight）：工具默认值 20×15×10 cm、实重 0.3 kg、除数 6000、进位 0.1 kg、每 kg ¥200、挂号及附加费 ¥10；`shippingWeight` 计算：体积重 0.5 kg，取大后计费重 0.5 kg，运费 ¥110；按实重的对比 0.3 × 200 + 10 = ¥70 为同一公式的算术。脚注照搬工具提示：除数和报价以物流商确认为准。
- **V-T04 合作定价核算**（/tools/partner-pricing）：工具默认值（`defaultPartnerPricing`）：成本 150，Etsy 变动费率 9.5% + 每单 0.45，广告 15%，合作分成 7%（扣平台费与广告后），毛利底线 45%，目标净利 15%。`partnerPricing` 结果：保本价 214.23，建议售价 273（精确值 272.73），按建议价 Etsy 费 26.39、广告 40.95、分成 14.40、最终利润 41.27（15.12%），广告保本上限 85.32（31.25%）。脚注照搬工具说明：默认费率是模型假设，不是店铺实际账单；币种按填写的成本。
- **V-T05 AI 披露文案**（/tools/ai-disclosure）：Etsy 创造力标准要求用 AI 创作的商品在商品描述中披露（etsy.com/legal/creativity，TechCrunch 2024-07-09 报道原文："Sellers must disclose within their listing description if an item is created with the use of AI."）。英文句子 "This item includes a design created with the assistance of AI." 和中文提示「不要写成商品由 AI 创作，请按商品的实际制作过程说明」都是工具原文（`aiDisclosure`、`disclosureNotAi`）。

## 声音

- 配乐：原创曲子写成 MIDI，用 FluidR3 GM 音色库（MIT 授权）经 FluidSynth 演奏：电钢琴琶音、暖色铺底、合成贝斯、颤音琴旋律、干净鼓组；A 小调 Am–F–C–G，第 24 拍 C 大调落地。五条共用一首，形成系列感。
- 音效：本机合成（点击、弹出、错误提示、提示音、风声），按各集画面时间点放置。母带约 −13.8 LUFS，峰值 −1.5 dBFS。

## 重新出片

```sh
cd source   # 需要 npm i playwright sharp、Chromium、ffmpeg、fluidsynth + fluid-soundfont-gm、pip mido
python3 music_t.py                                         # → mix_t_<ep>.wav
# 母带：acompressor=threshold=0.08:ratio=2.5:attack=15:release=250，再增益到 −13.8 LUFS，alimiter=limit=0.84
FILM="filmT.html?ep=tags" KMIN=2 node render_av.mjs 1080 1920 v.mp4   # ep = tags | title | ship | partner | ai
```
