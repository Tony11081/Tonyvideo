# V-W03 分镜（v1，30 秒，24 帧，80 BPM）

网站宣传片 · 发布会电影感版（openaigrowth.com / Shopwright）。竖版 1080×1920（抖音），横版 1920×1080，横版画面为 2.39:1 宽银幕，字幕在下方黑边里。同一条时间线（`timelineK.js`）。

**一句话概念**：发布会开场片的节奏。一片黑，一束光，一次只讲一件事。荧光绿光点贯穿全片：先在黑暗中亮起，再扫过片名把字点亮，在标题里当光标，在利润长条上跟着被切走的钱后退，沿流水线点亮每个节点，最后在一拍静音之后落成「Shopwright.」的句号。

## 事实出处

与 V-W01、V-W02 相同，界面文字和数字全部取自 openaigrowth.com 线上页面和仓库源码，2026-10-13 核对，没有编造的用户数、销量或评价。

- 标题章：终端演示 `skill/listing · run 0428`，输入 Maple cake server set / Laser engraving / 2 fonts · 3 woods / unknown: Blade steel grade；标题 74 字符（上限 140）。与首页 hero 演示一致。
- 标签章：同一条演示 listing 的 13 个标签；13 是 Etsy 的标签上限（网站 13 标签检查工具）。
- 利润章：网站利润计算器默认示例（`src/lib/calculator/profit.ts`）：售价 $25 + 买家运费 $5，收款地中国，汇率 7.10，上架费 $0.20、交易费 $1.95、支付处理费 $2.25，结汇 1%，成本 ¥40 / 包装 ¥5 / 物流 ¥70，利润 ¥64.94（30.5%）。画面下方常驻示例脚注。
- 上架章：首页 7 步流水线：产品机会分析 → 原创产品方向 → 工艺审查 → 设计系列 → SKU 与定制选项 → 上架资料包 → 15 图拍摄规划。
- 闪回：首页工作台的 6 个模块；6 个免费工具，「74/140 ✓」「13/13 ✓」是同一条演示 listing 的真实检查结果；完整标题。
- 「免费 Etsy 工具，不用登录」：工具页原文「免费计算，无需登录」。
- 开场「开一家 Etsy 店，要做的事太多了」是泛指的感受，不是数据。

## 视觉与声音

- 布光：纯黑背景，荧光绿 #c8ff00 主光，冷白轮廓光；变形镜头光斑、景深、地面倒影、暗角，胶片颗粒逐帧变化。
- 24 帧，180° 快门运动模糊（每帧按运动量取 4–16 个子帧）。
- 音乐（v2，10-13 按 Lambert「配乐不好听」重做）：原创曲子写成 MIDI（`score_k.py`），用开源音色库 FluidR3 GM（MIT 授权）经 FluidSynth 演奏。两版同一首曲子、同一套节点：
  - A · 钢琴 + 弦乐 + 定音鼓：A 小调，Am–F–C–G，钢琴八分音符琶音加主旋律，章节开头定音鼓，闪回三下全奏重音，静音一拍后 C 大调九和弦收尾，钢片琴点缀光点出现、落点和网址。
  - B · 电钢琴 + 合成铺底 + 干净鼓组：同一和声和旋律，四拍底鼓、拍手和踩镲。
  - 界面音效（打字、标签、切费用、流水线、闪回）仍为本机合成（`sfx_k.py`），压在音乐下面。母带 −13.6 LUFS，峰值 −1.5 dBFS。
  - v1 的纯合成配乐（`music_k.py`）保留在源码里，不再使用。

## 重新出片

```sh
cd source   # 需要 npm i playwright sharp，以及 Chromium 和 ffmpeg
node -e "const T=require('./timelineK.js');require('fs').writeFileSync('eventsK.json',JSON.stringify({BEAT:T.BEAT,duration:T.duration,at:T.at,typeT0:T.typeT0,typeT1:T.typeT1,tags:T.tagTimes,cuts:T.cutTimes,pipe:T.pipeTimes}))"
python3 sfx_k.py                                    # → sfx_k.npy（界面音效）
python3 score_k.py A                                # → score_A_pre.wav（需要 fluidsynth、fluid-soundfont-gm、pip mido）
# 母带：acompressor=threshold=0.06:ratio=3:attack=15:release=300，再增益到 −13.6 LUFS，alimiter=limit=0.84
FILM=filmK.html node render_av.mjs 1080 1920 v.mp4  # 竖版无声
FILM=filmK.html node render_av.mjs 1920 1080 h.mp4  # 横版无声
```
